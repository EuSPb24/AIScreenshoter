**AIScreenshoter** — легкая фоновая утилита для Windows (10, 11), которая перехватывает снимки экрана и помогает за пару секунд подготовить понятное визуальное ТЗ для нейросетей или коллег.

> Это не тяжелый графический редактор. Суть утилиты — за пару секунд выделить область, черкнуть стрелку, скрыть пароли и одним `Ctrl + V` вставить в чат готовую картинку со всеми пояснениями снизу.

---

## Особенности утилиты

* **Мгновенный перехват буфера обмена**
  Утилита работает в системном трее и автоматически открывает холст разметки при нажатии стандартных `Win + Shift + S` или `PrintScreen`. Снимки обрабатываются 1:1 в физических пикселях без размытия и сдвигов на мониторах с разным масштабированием DPI (включая связки FullHD + 2K/4K).
* **Инструменты разметки с умным расположением меток**
  * **Прямоугольник** — выделение области интерфейса с присвоением порядкового номера акцента.
  * **Линия и Стрелка** — подчеркивание текста и точное указание элементов с автовыравниванием по горизонтали/вертикали. Номер ставится у основания и автоматически сдвигается при плотной разметке, чтобы не перекрывать текст и кончик стрелки.
  * **Размытие (Блюр)** — необратимое скрытие паролей, токенов и личных данных перед отправкой скриншота.
  * **Выделить всё** — быстрое выделение всего текущего слоя в один клик из списка инструментов.
* **Редактирование на лету и визуальные акценты**
  Клик по любому кружку с номером (`1`, `2`, `3`...) открывает редактирование текста прямо рядом с меткой. Если нажать `Enter` с пустой строкой, на картинке останется только визуальная метка без лишней записи в подвале\*.
* **Многослойная сессия (серия скриншотов в одном кадре)**
  Повторное нажатие `Win + Shift + S` во время работы автоматически прячет интерфейс утилиты до заморозки экрана и добавляет новый снимок как следующий слой (`1/2`, `2/2`...). При сохранении все слои склеиваются в единую вертикальную ленту со сквозной нумерацией.
* **Готовая картинка + текст в один клик (дальше `Ctrl + V` в чат)**
  По нажатию **OK** утилита автоматически приклеивает снизу темный подвал\* с адаптивным размером шрифта и списком всех комментариев, копирует итоговое изображение в буфер обмена (для мгновенной вставки в чат ИИ) и сохраняет в папку `Изображения\AIScreenshoter\ГГГГ-ММ` три файла: чистый исходник (`_clean`), размеченный снимок (`_marked`) и проект `.ai` для повторного открытия и правки меток.
* **Нативная проверка орфографии Windows**
  В поле комментария встроен системный проверщик правописания Windows: опечатки подчеркиваются красной волнистой линией на языке текущей раскладки клавиатуры (русский, английский, китайский, французский, итальянский и др.), а по правому клику предлагаются варианты исправления.
* **Мультиязычность (`RU` / `EN` / `ZH` + свои языки)**
  Автоматически определяет язык Windows при первом запуске и поддерживает добавление собственных `.ini` переводов в `%APPDATA%\AIScreenshoter\lang\`.

> **\* Как работает подвал с комментариями:**
> Большинство чатов с ИИ и мессенджеров не позволяют одновременно вставить из буфера обмена и картинку, и текст — приходится сначала вставлять скриншот, а потом отдельно дописывать, что изображено под цифрами `1`, `2` и `3`.
> **AIScreenshoter** решает эту проблему автоматически:
> * Когда вы нажимаете зеленую кнопку (сохранить), программа сама дорисовывает снизу к вашему скриншоту аккуратную темную плашку со всеми вашими текстовыми комментариями, привязанными к номерам меток (`1`, `2`, `3`...).
> * В буфер обмена попадает одна цельная картинка, где сверху находится сам скриншот со стрелками и рамками, а сразу под ним — читаемая расшифровка каждого пункта.
> * Размер шрифта и значков в этой нижней плашке автоматически подстраивается под ширину снимка: даже если вы нажали `PrintScreen` и выделили сразу окна двух мониторов, текст останется крупным и легко читаемым как для вас, так и для нейросети.
> * Вам остается просто нажать `Ctrl + V` в окне чата с ИИ или в мессенджере — и собеседник сразу увидит всю картину целиком без лишних сообщений.

## Установка и запуск

### Вариант 1. Готовый установщик (для пользователей)
1. [Скачайте](https://github.com/EuSPb24/AIScreenshoter/releases/download/v1.2.4/AIScreenshoter_Setup_1.2.4.exe) **`AIScreenshoter_Setup_1.2.4.exe`** (прямая загрузка) или выберите нужную версию на странице [Releases](https://github.com/EuSPb24/AIScreenshoter/releases).
2. Запустите установщик (установленный Python не требуется).
3. Утилита появится в системном трее. Нажмите `Win + Shift + S` или `PrintScreen` для начала работы.

---

### Вариант 2. Полная сборка `.exe` и установщика (`build.py` + `installer.iss`)
Подходит, если вы хотите собрать автономный `AIScreenshoter.exe` и дистрибутив `AIScreenshoter_Setup_1.2.4.exe` самостоятельно.

**Требования:** Windows 10/11, **Python 3.11+**, **Inno Setup 6 или 7** (для компиляции `installer.iss`).

```bash
git clone https://github.com
cd AIScreenshoter
pip install PySide6 pyinstaller
python build.py
```

**Что сделает скрипт `build.py`:**
1. Сгенерирует иконку `app_icon.ico` из векторного `assets.py`.
2. Упакует приложение и `.ini` локализации в один файл **`dist/AIScreenshoter.exe`**.
3. Автоматически найдет компилятор Inno Setup (`ISCC.exe`) и соберет установщик **`dist_setup/AIScreenshoter_Setup_1.2.4.exe`** на основе сценария **`installer.iss`**.

*(При необходимости скрипт `installer.iss` можно открыть и скомпилировать вручную через графическую оболочку Inno Setup Compiler).*

---

### Вариант 3. Запуск и разработка в Visual Studio Code (VS Code)
1. Склонируйте репозиторий и откройте папку проекта в **VS Code** (`File → Open Folder...`).
2. Установите официальное расширение **Python** от Microsoft (если не установлено).
3. Откройте встроенный терминал в VS Code (`Ctrl + ~`) и установите зависимость:
   ```bash
   pip install PySide6
   ```
4. Выберите файл **`main.py`** и нажмите **`F5`** (запуск с отладкой) или **`Ctrl + F5`** (быстрый запуск без отладки).
5. Иконка утилиты сразу появится в системном трее Windows.

## ⌨️ Горячие клавиши и управление

| Действие | Управление |
| :--- | :--- |
| Сделать снимок / добавить новый слой | `Win + Shift + S` или `PrintScreen` |
| Подтвердить комментарий к метке | `Enter` (перенос строки: `Shift + Enter`) |
| Отредактировать текст существующей метки | Клик левой кнопкой по кружку с номером (`1`, `2`...) |
| Переключение между слоями | Кнопки `◀` / `▶` в шапке или `PageUp` / `PageDown` |
| Отмена / возврат действия в текущем слое | Кнопки `↶` / `↷` |
| Закрыть без сохранения | Двойное нажатие `ESC` (если на холсте есть метки) |
